## Architecture decisions

- Independent Next.js 16.4 JavaScript repository and Netlify site boundary; App Router and a server Route Handler.
- Additive extension of protected `gnz_leads`, preserving existing investor/contact records and Admin authentication.
- Service credential remains server-only. Browser roles retain no lead-table access.
- Database-backed atomic request limiting with hashed identifiers; origin, payload-size, honeypot, timing, Turnstile, validation, and idempotency controls.
- Notification email contains only the lead reference and secure Admin link. Full lead details remain in the protected Admin.
- Static content stays server-rendered; client JavaScript is limited to navigation, analytics hooks, anti-spam, and the form.
- Preview and branch builds are noindex by default. Indexing requires an explicit environment switch and launch approval.

## Migration and rollback

The migration adds seller/source/property/attribution/consent/assignment fields, expands status values, and adds notification logs, minimized audit records, indexes, RLS, grants, and atomic rate limiting. It has **not** been applied.

Rollback is provided but drops seller data and shared columns. Prefer application rollback; use SQL rollback only after backup, impact review, and explicit approval.
